GUÍA DE CONFIGURACIÓN

Ayuda de faveo-ticket-labels

La extensión asocia citas de Google Calendar a tickets de Faveo Helpdesk y muestra una etiqueta con la cita en cada ticket. Aquí tienes cada ajuste por separado: sigue solo los apartados que necesites.

SIEMPRE

Necesario en cualquier modo

  • Contraseña maestra para cifrar las citas.
  • URL de Faveo y ruta del ticket.
  • Modo de guardado de las citas.

SOLO MODO API

Para sincronizar con tu agenda

  • Disponibilidad real: las horas ocupadas se bloquean.
  • Crea, mueve y borra eventos sin abrir Google Calendar.
  • La lista del popup se reconstruye desde el calendario.

Requiere el cliente OAuth y el ID del calendario.

EMPEZAR

Primer uso y contraseña maestra

Al instalar la extensión se abre Preferencias. Hasta que no crees la contraseña maestra, el popup solo mostrará el botón Abrir preferencias y no permitirá guardar citas.

  1. Crea la contraseña maestra

    En Preferencias → Seguridad → Contraseña maestra (obligatoria: hasta que exista, la extensión y el resto de ajustes están bloqueados), pulsa Crear contraseña con al menos 12 caracteres y repítela. Con ella se cifran las citas guardadas y, en modo API, las credenciales de Google.

  2. Indica tu Faveo y el modo de guardado

    Completa la dirección de Faveo y el modo de guardado, y pulsa Guardar preferencias. Firefox te pedirá permiso para acceder a tu Faveo.

  3. Recarga Faveo y abre el popup

    Recarga las pestañas de Faveo abiertas. Después de guardar, la sesión queda desbloqueada y ya puedes crear citas desde el popup.

Importante: la contraseña no se puede recuperar. Si la olvidas, tendrás que volver a introducir las credenciales y las citas cifradas no se podrán leer. Cada vez que abras Firefox de nuevo, o pulses Cerrar sesión, el popup la pedirá.

CONFIGURACIÓN

Dirección de Faveo

En Preferencias → Dirección de Faveo hay dos campos:

URL de Faveo Helpdesk
La dirección base, sin rutas: https://helpdesk.tuorganizacion.es. La extensión solo se activa en ese sitio.
Ruta del ticket
Lo que va detrás de la URL base. Usa {ticket} donde va el número. Por defecto /thread/{ticket}.

La descripción de cada evento incluye la línea Ticket: #120 y un enlace formado por {URL de Faveo}{ruta del ticket}.

CONFIGURACIÓN

Modo de guardado

En Preferencias → Calendario eliges qué ocurre al guardar una cita:

Abrir una pestaña

Abre Google Calendar con la cita preparada. No consulta tu agenda, no bloquea horas ocupadas y no puede modificar ni borrar el evento después. No necesita nada más de esta guía.

Crear mediante la API

Lee el calendario de destino, bloquea las horas ocupadas y crea, mueve y borra los eventos. Requiere completar el apartado de Google.

CONFIGURACIÓN

Horario de trabajo

En Preferencias → Horario de trabajo defines en qué horas se pueden reservar citas. Cada tramo tiene sus días de la semana y una hora de inicio y de fin. Para un turno partido, añade un tramo por cada parte:

  • De 08:00 a 15:00, de lunes a viernes.
  • De 16:00 a 18:30, martes y jueves.

El popup solo ofrece franjas de 15 minutos dentro de estos tramos. Los tramos no pueden solaparse en un mismo día: al marcar un día y una hora que ya cubre otro tramo, se avisa al momento y no se puede guardar hasta corregirlo. Si no cambias nada, se usa de lunes a viernes de 08:00 a 15:00.

Duraciones de reserva

En el mismo apartado eliges qué duraciones aparecen al reservar (por defecto 15 min, 30 min y 1 h). Puedes añadir las que quieras, entre 5 y 480 minutos, y quitar las que no uses, siempre que quede al menos una. Quitar una duración no cambia las citas ya creadas con ella ni sus eventos del calendario; si editas una de ellas, su duración sigue apareciendo marcada como «ya no disponible» hasta que la cambies.

MODO API

Datos necesarios

Solo si eliges Crear mediante la API. Google Cloud no muestra un token listo para copiar: la consola configura la API y el cliente OAuth, y OAuth Playground obtiene los tokens tras tu consentimiento. Al final tendrás cuatro datos:

ID de cliente
123456789012-************************.apps.googleusercontent.com
Secreto del cliente
GOCSPX-****************************
Refresh token
1//**********************************************************
ID del calendario
abc123************************@group.calendar.google.com

Un valor que empieza por ya29. es un Access token (caduca en una hora) y no sirve.

MODO API · PASO 1

Preparar Google Cloud

  1. Crea o selecciona un proyecto

    Abre la Consola de Google Cloud, inicia sesión y usa el selector de proyectos de la barra superior. Crea un proyecto o elige uno existente.

  2. Habilita Calendar API

    En el menú, sigue APIs y servicios → Biblioteca → Google Workspace. Busca y abre API de Calendario y pulsa Habilitar. Comprueba que el proyecto seleccionado sea el correcto.

  3. Configura la plataforma de autenticación

    Si la consola muestra Comenzar, inicia el asistente. Completa todos sus apartados: en Información de la app, indica Nombre de la app y Correo electrónico de asistencia al usuario; en Público, elige el tipo de usuario; en Información de contacto, introduce un correo de desarrollador; y en Finalizar, acepta la política y pulsa Continuar y Crear.

    Después, en Información de la marca, revisa el nombre y el correo de asistencia. Para cuentas personales elige Externo; Interno solo sirve para cuentas de tu organización de Google Workspace.

  4. Añade el permiso de Calendario

    Abre Acceso a los datos → Agregar o quitar permisos y añade este permiso OAuth, que permite a la extensión encontrar tu calendario de citas y consultar, crear, modificar o borrar sus eventos:

    https://www.googleapis.com/auth/calendar

    No uses calendar.events: el permiso calendar es el que se ha probado con la extensión.

    Si el apartado sigue bloqueado, vuelve al asistente y completa cualquier campo obligatorio marcado; guarda los cambios y vuelve a cargar la consola.

  5. Crea un cliente OAuth para Playground

    Ve a Plataforma de autenticación de Google → Clientes → Crear cliente. En Tipo de aplicación, selecciona Aplicación web. En URIs de redireccionamiento autorizados, añade exactamente esta dirección:

    https://developers.google.com/oauthplayground

    Pulsa Crear. Guarda el ID de cliente y el Secreto del cliente; no compartas el secreto.

MODO API · PASO 2

Obtener el token en OAuth Playground

Los nombres coinciden con la consola en español; Playground conserva sus botones en inglés.

  1. Usa las credenciales del proyecto

    Abre OAuth 2.0 Playground. Pulsa el engranaje, activa Use your own OAuth credentials e introduce el ID de cliente y el secreto del paso anterior. Si aparece la opción Access type, selecciona Offline para recibir un Refresh token. Cierra el panel de ajustes.

  2. Solicita permiso para el calendario

    En Step 1: Select & authorize APIs, escribe https://www.googleapis.com/auth/calendar en el campo de scopes y pulsa Authorize APIs. Inicia sesión con la cuenta propietaria del calendario y acepta el consentimiento. Si aparece «Google no ha verificado esta aplicación», pulsa Avanzado → Ir a (nombre de tu app).

  3. Canjea el código y copia el token

    Cuando Playground vuelva a mostrar el código de autorización, todavía no lo copies en la extensión. En Step 2: Exchange authorization code for tokens, pulsa Exchange authorization code for tokens. Copia el Refresh token (empieza por 1//) en ese momento. El Access token (ya29.…) dura aproximadamente una hora y la extensión lo renueva sola; no lo pegues en las preferencias.

    Si no aparece un Refresh token, revisa en los ajustes de Playground que el acceso sea Offline. Si ya autorizaste ese cliente, revoca su acceso en tu Cuenta de Google y repite la autorización para que Google emita uno nuevo.

No compartas el Refresh token: permite obtener nuevos Access tokens en nombre de tu cuenta.

MODO API · PASO 3

ID del calendario de citas

En modo API la extensión usa el calendario cuyo ID indiques para leer la disponibilidad y para crear, mover y borrar eventos. Si el ID no es válido o no tienes permiso de escritura, mostrará un error. Usa la misma cuenta de Google que autorizaste en Playground:

  1. Abre Google Calendar

    Google Calendar. Si no existe aún, créalo con Otros calendarios → + → Crear un calendario.

  2. Abre su configuración

    Pulsa los tres puntos junto al calendario y elige Configuración y uso compartido.

  3. Copia el ID

    En Integrar el calendario, copia el ID del calendario. Acaba en @group.calendar.google.com; en tu calendario principal es tu correo.

Con la línea Ticket: #120 de cada evento, la extensión reconstruye la lista del popup a partir del calendario (próximos 90 días); la copia local solo se usa si no se puede leer. Los eventos creados antes en otro calendario no se mueven: bórralos a mano y vuelve a guardar la cita.

MODO API · PASO 4

Pegar los datos en Preferencias

  1. Elige el modo API

    En 3 · Calendario, selecciona Crear mediante la API y pega el ID del calendario de destino.

  2. Rellena el acceso a Google

    En 4 · Acceso a Google, pega el ID de cliente, el secreto y el Refresh token. Deben ser del mismo cliente OAuth.

  3. Guarda

    Pulsa Guardar preferencias. Las credenciales se cifran con tu contraseña maestra.

USO DIARIO

Sesión y cifrado

  • Las citas y las credenciales se guardan cifradas (AES-GCM) con una clave derivada de tu contraseña maestra.
  • Al abrir Firefox, el popup pide la contraseña; mientras la sesión esté bloqueada no muestra citas ni permite usar la extensión.
  • El botón Cerrar sesión del popup bloquea la sesión al instante.
  • Para cambiarla, usa Actualizar contraseña en Preferencias → Seguridad con la sesión desbloqueada.

USO DIARIO

Avisos de red

En modo API, la extensión comprueba cada minuto que puede llegar a Google Calendar. Si se pierde la conexión, Firefox muestra una notificación; también avisa cuando vuelve. Las citas guardadas sin conexión quedan marcadas como Pendiente de sincronizar y se envían al calendario cuando hay red.

USO DIARIO

Solución de problemas

«The provided client secret is invalid»
El secreto no corresponde al ID de cliente (suele ser un ya29.… o el secreto de otro cliente).
invalid_grant
El Refresh token es de otro cliente o está caducado: repite el paso 2 con tu cliente.
No aparecen etiquetas en Faveo
Comprueba la URL en Dirección de Faveo, concede el permiso que pide Firefox y recarga la pestaña de Faveo.
El popup se queda abierto al hacer clic fuera
En about:config, la opción ui.popup.disable_autohide debe estar en false. Es un ajuste de Firefox que la extensión no puede cambiar.
