GUÍA DE CONFIGURACIÓN

GOOGLE CALENDAR · OAUTH 2.0

Conecta tu calendario

Solo necesitas esta guía si quieres el modo Crear mediante la API. Con Abrir una pestaña no hace falta configurar nada.

QUÉ HACE LA API

Conecta la extensión con tu calendario de citas

Con el modo Crear mediante la API, la extensión trabaja directamente con el calendario de Google cuyo ID indiques en Preferencias:

  • Muestra la disponibilidad: las horas que chocan con otros eventos aparecen bloqueadas al elegir la franja.
  • Crea, mueve y borra los eventos al guardar, cambiar o quitar una cita, sin que tengas que abrir Google Calendar.
  • Recupera tus citas: la lista del popup se reconstruye desde el calendario, así que no se pierde si se borran los datos del navegador.

Con el modo Abrir una pestaña, la extensión solo abre Google Calendar con la cita preparada. No consulta tu agenda, no bloquea horas ocupadas y no puede modificar ni borrar el evento después, por lo que no necesita nada de esta guía.

LOS 4 DATOS QUE NECESITAS

Del cliente OAuth y del calendario

ID de cliente
123456789012-************************.apps.googleusercontent.com
Secreto del cliente
GOCSPX-****************************
Refresh token
1//**********************************************************
ID del calendario
abc123************************@group.calendar.google.com

Un valor que empieza por ya29. es un Access token (caduca en una hora) y no sirve. El ID del calendario se obtiene en Google Calendar (mira «Tu calendario de citas», más abajo).

Google Cloud no muestra un token listo para copiar: la consola configura la API y el cliente OAuth, y OAuth Playground obtiene los tokens tras tu consentimiento. Los nombres coinciden con la consola en español; Playground conserva sus botones en inglés.

Preparar Google Cloud

  1. Crea o selecciona un proyecto

    Abre la Consola de Google Cloud, inicia sesión y usa el selector de proyectos de la barra superior. Crea un proyecto o elige uno existente.

  2. Habilita Calendar API

    En el menú, sigue APIs y servicios → Biblioteca → Google Workspace. Busca y abre API de Calendario y pulsa Habilitar. Comprueba que el proyecto seleccionado sea el correcto.

  3. Configura la plataforma de autenticación

    Si la consola muestra Comenzar, inicia el asistente. Completa todos sus apartados: en Información de la app, indica Nombre de la app y Correo electrónico de asistencia al usuario; en Público, elige el tipo de usuario; en Información de contacto, introduce un correo de desarrollador; y en Finalizar, acepta la política y pulsa Continuar y Crear.

    Después, en Información de la marca, revisa el nombre y el correo de asistencia. Para cuentas personales elige Externo; Interno solo sirve para cuentas de tu organización de Google Workspace.

  4. Añade el permiso de Calendario

    Cuando hayas terminado y creado la configuración inicial, abre Acceso a los datos → Agregar o quitar permisos. Añade este permiso OAuth: permite a la extensión encontrar tu calendario de citas y consultar, crear, modificar o borrar sus eventos:

    https://www.googleapis.com/auth/calendar

    No uses calendar.events: el permiso calendar es el que se ha probado con la extensión.

    Si el apartado sigue bloqueado, vuelve al asistente y completa cualquier campo obligatorio marcado; guarda los cambios y vuelve a cargar la consola.

  5. Crea un cliente OAuth para Playground

    Ve a Plataforma de autenticación de Google → Clientes → Crear cliente. En Tipo de aplicación, selecciona Aplicación web. En URIs de redireccionamiento autorizados, añade exactamente esta dirección:

    https://developers.google.com/oauthplayground

    Pulsa Crear. Guarda el ID de cliente y el Secreto del cliente: identifican tu aplicación OAuth y los necesitarás tanto en OAuth 2.0 Playground como en las preferencias de la extensión. No compartas el secreto.

Obtener el token en OAuth Playground

  1. Usa las credenciales del proyecto

    Abre OAuth 2.0 Playground. Pulsa el engranaje, activa Use your own OAuth credentials e introduce el ID de cliente y el secreto del paso anterior. Si aparece la opción Access type, selecciona Offline para recibir un Refresh token. Cierra el panel de ajustes.

  2. Solicita permiso para el calendario

    En Step 1: Select & authorize APIs, escribe https://www.googleapis.com/auth/calendar en el campo de scopes y pulsa Authorize APIs. Inicia sesión con la cuenta propietaria del calendario y acepta el consentimiento. Si aparece «Google no ha verificado esta aplicación», pulsa Avanzado → Ir a (nombre de tu app).

  3. Canjea el código y copia el token

    Cuando Playground vuelva a mostrar el código de autorización, todavía no lo copies en la extensión. En Step 2: Exchange authorization code for tokens, pulsa Exchange authorization code for tokens. Copia el Refresh token (empieza por 1//) y hazlo en ese momento. El ID y el secreto son los del cliente que creaste en Google Cloud, no los que muestre Playground por defecto. El Access token (ya29.…) dura aproximadamente una hora y la extensión lo renueva sola; no lo pegues en las preferencias.

    Si no aparece un Refresh token, revisa en los ajustes de Playground que el acceso sea Offline. Si ya autorizaste ese cliente, revoca su acceso en tu Cuenta de Google y repite la autorización para que Google emita uno nuevo.

    En el popup, abre Preferencias, elige Crear mediante la API y pega el ID de cliente, el secreto y el Refresh token, y en Calendario de destino pega el ID del calendario. Pulsa Guardar preferencias. No compartas el Refresh token: permite obtener nuevos Access tokens en nombre de tu cuenta.

    Si al abrir el popup aparece «The provided client secret is invalid», el secreto no corresponde al ID de cliente (suele ser un ya29.… o un secreto de otro cliente). Si aparece invalid_grant, el Refresh token es de otro cliente o está caducado: repite este paso con tu cliente.

DESTINO DE LOS EVENTOS

Tu calendario de citas

En modo API la extensión usa el calendario cuyo ID indiques en Preferencias → Calendario de destino para leer la disponibilidad y para crear, mover y borrar eventos. Si el ID no es válido o no tienes permiso de escritura, mostrará un error.

Para obtener el ID (con la misma cuenta de Google que autorizaste en Playground):

  1. Abre Google Calendar (créalo antes con Otros calendarios → + → Crear un calendario si no existe).
  2. Pulsa los tres puntos junto al calendario y elige Configuración y uso compartido.
  3. En Integrar el calendario, copia el ID del calendario (acaba en @group.calendar.google.com; en tu calendario principal es tu correo) y pégalo en Preferencias.

La descripción de cada evento incluye la línea Ticket: #120 y un enlace al ticket ({URL de Faveo}{ruta del ticket}, configurable en Preferencias; por defecto /thread/120). Con ella la extensión reconstruye la lista de citas del popup a partir del calendario (próximos 90 días); la copia local solo se usa si no se puede leer.

Los eventos creados antes en otro calendario no se mueven: bórralos a mano y vuelve a guardar la cita.
