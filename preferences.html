PREFERENCIAS

Calendario

Elige cómo añadir las citas. Solo el modo API necesita la conexión OAuth; el modo de pestaña no consulta tu calendario.

FAVEO HELPDESK

Dirección de Faveo

Es la dirección base de tu Faveo, sin rutas, por ejemplo https://helpdesk.tuorganizacion.es. La extensión solo se activa en ese sitio y la usa para crear el enlace al ticket en los eventos. Al guardar, Firefox te pedirá permiso para acceder a esa dirección. Si ya tenías una pestaña de Faveo abierta, recárgala.

ENLACE DEL TICKET

Ruta del ticket

Es la parte de la dirección que va detrás de la URL base. Usa {ticket} donde va el número del ticket. Por defecto /thread/{ticket}. Es el único dato, junto con el número, que se escribe en el evento de Calendar.

GOOGLE CALENDAR

Calendario de destino

Es el calendario de tu cuenta de Google donde se crean y leen las citas. Para obtenerlo: en Google Calendar pulsa los tres puntos junto al calendario → Configuración y uso compartido → Integrar el calendario → ID del calendario. Es obligatorio en modo API. Para tu calendario principal, usa tu dirección de correo.

CONEXIÓN CON GOOGLE (SOLO MODO API)

Acceso al calendario

Los tres datos se guardan cifrados con esta contraseña (mínimo 8 caracteres). Firefox te la pedirá una vez cada vez que lo abras, al usar el popup. No se puede recuperar: si la olvidas, tendrás que volver a introducir las credenciales. Si ya están desbloqueadas, déjala en blanco para conservarla o escribe una nueva para cambiarla.

Los tres datos deben ser del mismo cliente OAuth. Cópialos de Google Cloud → Clientes (ID y secreto) y de OAuth 2.0 Playground (Refresh token, con el permiso https://www.googleapis.com/auth/calendar). Un valor que empiece por ya29. es un Access token y no sirve. La extensión renueva el Access token sola.
